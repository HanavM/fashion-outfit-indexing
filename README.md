Just for fun project, mostly for myself!

While shopping, if you want to know what something will look like with an apparel in your closet, you can ask Siri, "how would this look like with my jorts". 

Using a hybrid between SigLip for apparel caption alignment and DinoV3 for feature extraction, the pipeline finds images from Pinterest, Reddit, etc of people's outfits matching the query. 

Working on getting it into the app store right now.
