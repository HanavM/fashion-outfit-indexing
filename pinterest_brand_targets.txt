# Pinterest search grids, TARGETED AT THE 18 BRANDS IN apparel_dataset/.
# Companion to pinterest_targets.txt (generic style queries, already consumed).
#
# Why a brand-keyed list exists: measured 2026-08-05, the generic queries
# produced a corpus that barely overlaps the catalog -- 22% Japan/Korea
# sourced, 20% women's fashion against a 100% men's catalog, ~42%
# unmatchable by construction. Exact-product matching cannot work on a
# photo whose garments we do not stock. Selecting the photos BY the brands
# we carry is the most direct available fix.
#
# Construction rule: one query per brand PRODUCT LINE, not per brand.
# "nike outfit" returns a brand mood board; "nike air force 1 outfit men"
# returns photos plausibly containing a specific catalog SKU. Every query
# is men's-qualified and US-centric, because the catalog is 100% men's and
# the generic list already over-collected women's and JP/KR street style.
#
# Breadth beats depth (same note as pinterest_targets.txt): one grid
# converges on one look, so run these with a MODEST --target (~35) rather
# than scrolling any one of them deep.
#
# Pinterest's robots.txt is `User-agent: * / Disallow: /`; this target is an
# explicit, reviewed exception by the project owner (docs/outfit_sourcing_plan.md,
# "Revision -- Pinterest is reachable"). Do NOT pass --respect-robots here or
# every line is skipped. Requires the logged-in profile in
# ~/.cache/fashion-tests/browser-profile.
