# Pinterest search grids -- BREADTH PASS 3. One query per line.
#
# Companions: pinterest_targets.txt (20 generic style queries, consumed
# 2026-08-04) and pinterest_brand_targets.txt (per-brand product lines,
# consumed 2026-08-05). Neither query appears twice across the three files.
#
# Why this list exists: after both passes the owner still reported "not that
# much outfit image diversity". Passes 1 and 2 were keyed on LOOK (streetwear,
# techwear, ootd) and on BRAND SKU (nike dunk low, carhartt detroit jacket).
# Both axes were exhausted, and a grid keyed on either converges hard -- one
# query's grid is one look. So this pass keys on five axes that neither
# earlier list touched at all:
#
#   occasion/context  (interview, wedding guest, airport, game day)
#   season/weather    (layering, rainy day, transitional fall, snow day)
#   aesthetic         (prep, ivy, normcore, gorpcore, blokecore, western)
#   garment           (chore coat, henley, corduroy, painter pants, overshirt)
#   colour            (red sneakers, yellow jacket, orange hoodie, all black)
#   body/region       (tall, big, over 40, NYC, LA, Pacific Northwest)
#
# The colour block is deliberate and measured: across 31,239 catalog crops
# there are only 55 red-FOOTWEAR crops and 389 red crops of any type, and the
# owner searches by colour. Saturated colours are the corpus's thinnest axis.
#
# Every query is men's-qualified and US-centric, for the same reason
# pinterest_brand_targets.txt is: the catalog is 20 US brands, 100% men's,
# while 22% of the existing corpus is JP/KR-sourced and 20% is women's --
# ~42% unmatchable by construction. Nothing here should add to that pile.
#
# Queries deliberately NOT repeated, measured as failures in earlier passes:
# `skechers mens outfit` and `skechers slip ins mens style` (retail ads, no
# organic outfit-pin culture), `gap mens outfit` (23 items) and
# `pacsun mens outfit` (19 items).
#
# Run with a MODEST --target (~40). Breadth beats depth: a dozen disjoint
# queries buy far more variety than a deeper scroll of one.
#
# Pinterest's robots.txt is `User-agent: * / Disallow: /`; this target is an
# explicit, reviewed exception by the project owner (docs/outfit_sourcing_plan.md,
# "Revision -- Pinterest is reachable"). Do NOT pass --respect-robots here or
# every line is skipped. Requires the logged-in profile in
# ~/.cache/fashion-tests/browser-profile.
#
# The grid DOM carries no pinner, so ALWAYS follow a run with
# `python3 backfill_pin_authors.py` (no --ids-file) -- docs/licensing_review.md
# requires an author on every Pinterest record.
